# Лабораторная работа №2

**Тема:** списки, строки, срезы, циклы.

**Вариант 10.**

Программа показывает меню из трёх заданий. Пользователь вводит номер задания,
затем исходные данные; после вывода результата нажатие Enter возвращает в меню.
Пункт `0` (или `выход`) завершает работу. Некорректный ввод не «роняет»
программу: запрос повторяется с пояснением, что именно введено неверно.

## Задания

### 1. Сумма членов функционального ряда

```
y(x) = -pi/2 + sum(n=0..inf) (-1)^(n+1) / ((2n+1) * x^(2n+1))
     = -pi/2 - 1/x + 1/(3x^3) - 1/(5x^5) + ...,   x < -1
```

Область сходимости `|x| > 1`. Сумма считается с заданной точностью `eps`:
очередной член добавляется к результату, пока его модуль не станет меньше `eps`.
Дополнительно выводится контрольное значение `arctg(x)` (сумма этого ряда равна
арктангенсу) и количество учтённых членов.

### 2. Символ посередине фразы

Пользователь вводит фразу длиной от 10 символов. Середина выделяется срезом
`середина = s[(len(s) - 1) // 2 : len(s) - (len(s) - 1) // 2]`. При нечётной длине
это один символ, при чётной — два центральных (выводятся оба). В ответе
показывается также номер символа и разбивка фразы на начало / середину / конец.

### 3. Статистика по списку из 6 элементов

Пользователь вводит через запятую 6 целых чисел. Программа выводит:

1. 4-й элемент списка;
2. все элементы, начиная с 3-го (`numbers[2:]`);
3. все элементы в обратном порядке (`numbers[::-1]`);
4. сумму и среднее арифметическое элементов.

| № | Файл | Что находится |
|---|------|---------------|
| 1 | `tasks/task1_series.py` | Сумма функционального ряда при `x < -1` |
| 2 | `tasks/task2_middle_char.py` | Символ посередине фразы через срезы |
| 3 | `tasks/task3_list_stats.py` | Статистика по списку из 6 чисел |

## Запуск

Требуется Python 3.8+ (сторонние библиотеки не используются).

```bash
cd LB-2
python main.py
```

## Структура

Каждый файл задания устроен одинаково:

* `TITLE` — короткое название для меню;
* `STATEMENT` — условие и формулы, которые печатаются перед вводом;
* `TASK` — постановка задачи из методички (там, где нужна для сверки);
* `solve(...)` — только расчёты, без ввода-вывода;
* `run()` — диалог с пользователем.

## Запуск одного задания без меню

```bash
cd LB-2/tasks
python task3_list_stats.py
```

или из каталога `LB-2`:

```bash
python -m tasks.task3_list_stats
```
