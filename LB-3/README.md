# Лабораторная работа №3

**Тема:** строки, списки, множества, многомерные массивы.

Программа показывает меню из шести заданий. Пользователь вводит номер задания,
затем исходные данные; после вывода результата нажатие Enter возвращает в меню.
Пункт `0` (или `выход`) завершает работу. Некорректный ввод не «роняет»
программу: запрос повторяется с пояснением, что именно введено неверно.

## Задания

### 1. Самое короткое и самое длинное слово

Дана строка, заканчивающаяся точкой. Программа находит длину самого короткого
и самого длинного слова. Точка в конце строки знаком слова не считается.
Если слов минимальной (или максимальной) длины несколько, выводятся все;
дополнительно печатается таблица «слово → длина» в порядке появления.

### 2. Перемещение отрицательных элементов с нечётным номером в «хвост»

Список заполняется генератором случайных чисел. Все отрицательные элементы
с нечётным порядковым номером (`a1`, `a3`, `a5`, …) переносятся в конец списка.
Нумерация в условии начинается с единицы, поэтому проверяется позиция
`position % 2 == 1` при `enumerate(..., start=1)`.

```
[3, -1, -4, -6, 7]  ->  [3, -1, -6, 7, -4]      перенесён a3 = -4
```

Перемещение устойчивое: порядок остальных элементов и взаимный порядок
перенесённых сохраняются, длина списка не меняется. В «Результате» отдельно
показаны перенесённая группа и остаток, а исходный список печатается
с пометками переносимых позиций.

### 3. Удаление отрицательных элементов между положительными

Список заполняется генератором случайных чисел. Удаляются отрицательные
элементы, у которых есть положительный сосед и слева, и справа
(«между положительными»). Нули положительными не считаются, поэтому элемент
между нулём и положительным числом сохраняется.

```
[1, -1, 2, -2, -3, 3]  ->  [1, 2, -2, -3, 3]    удалён только -1
[5, -3, 8, 0, -2, 0, -1, 4, -9]  ->  [5, 8, 0, -2, 0, -1, 4, -9]
```

В выводе показываются исходный список с пометкой удаляемых элементов,
список удалённых значений и результат.

### 4. Решето Эратосфена и числа, кратные 7

Решето реализовано точно по шагам из условия: список флагов от 2 до `n`,
`p = 2`, вычёркивание кратных `p` начиная с `2p`, затем новое `p` — первое
незачёркнутое число, большее предыдущего, и так пока `p * p <= n`.
Простые числа дополнительно собираются в множество, а числа от 1 до `n`,
кратные 7, — во множество (и выводятся отсортированными). В конце показана
проверка через множества: мощности и общие элементы (для `n >= 7` это только 7).

### 5. Чётные и нечётные числа в матрице

Целочисленная матрица `n x m` заполняется генератором случайных чисел.
Размерности заданы константами `ROWS` и `COLS` и выбираются из готовых
вариантов (`4x6`, `3x3`, `5x8`), диапазон значений — из двух наборов.
Подсчитываются чётные и нечётные числа, отдельно — количество нулей
(ноль чётный), а также выдаются доли в процентах и суммы, чтобы результат
было легко проверить вручную.

### 6. Наибольшее число в трёхмерном массиве

Массив `T` размерности `3x5x7` заполняется случайными числами и печатается
послойно. Программа находит наибольшее число и выводит его индексы во всех
трёх измерениях — как с нуля (как в Python), так и с единицы. Если максимум
встречается несколько раз, дополнительно печатаются все его позиции.

| № | Файл | Что находится |
|---|------|---------------|
| 1 | `tasks/task1_words_length.py` | Длина самого короткого и самого длинного слова |
| 2 | `tasks/task2_move_negatives.py` | Перенос отрицательных с нечётным номером в конец |
| 3 | `tasks/task3_remove_negatives.py` | Удаление отрицательных между положительными |
| 4 | `tasks/task4_sieve.py` | Решето Эратосфена и числа, кратные 7 |
| 5 | `tasks/task5_matrix_even_odd.py` | Чётные и нечётные числа в матрице |
| 6 | `tasks/task6_3d_max.py` | Максимум в массиве 3x5x7 и его индексы |

## Запуск

Требуется Python 3.8+ (сторонние библиотеки не используются).

```bash
cd LB-3
python main.py
```

Задания 2, 3, 5, 6 заполняют данные генератором случайных чисел; задания 2 и 3
спрашивают, задавать ли размер списка вручную (по умолчанию — 12 и 15).

## Структура

Каждый файл задания устроен одинаково:

* `TITLE` — короткое название для меню;
* `STATEMENT` — условие и формулы, которые печатаются перед вводом;
* `solve(...)` — только расчёты, без ввода-вывода;
* `run()` — диалог с пользователем.

## Запуск одного задания без меню

```bash
cd LB-3/tasks
python task4_sieve.py
```

или из каталога `LB-3`:

```bash
python -m tasks.task4_sieve
```
