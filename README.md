# Основы программирования - лабораторные работы, 1-й семестр

Репозиторий со всеми лабораторными работами первого семестра по дисциплине
**«Основы программирования»**. Каждая работа лежит в отдельном каталоге `LB-N`
и представляет собой самостоятельную консольную программу с меню выбора задания.

Язык реализации - **Python**. Все программы работают на стандартной библиотеке,
устанавливать сторонние пакеты не нужно.

## Список работ

| Каталог | Тема | Заданий | Статус |
|---------|------|:-------:|--------|
| [LB-1](LB-1/README.md) | Знакомство с инструментарием разработки. Арифметические операции | 7 | выполнена |
| [LB-2](LB-2/README.md) | Списки, строки, срезы, циклы | 3 | выполнена |
| [LB-3](LB-3/README.md) | Строки, списки, множества, многомерные массивы | 6 | выполнена |

## Как запустить работу

Каждая лабораторная запускается из своего каталога:

```bash
cd LB-1
python main.py
```

где `LB-N` - каталог нужной работы (`LB-1`, `LB-2`, ...).

Дальше программа сама подсказывает, что делать:

1. показывается меню со списком заданий;
2. пользователь вводит номер задания;
3. печатаются условие и формулы, затем запрашиваются исходные данные;
4. выводится результат, нажатие Enter возвращает в меню;
5. пункт `0` (или слово `выход`) завершает программу.

Некорректный ввод не прерывает работу: программа сообщает, что именно введено
неверно, и запрашивает значение повторно. Вещественные числа можно вводить как
через точку (`4.5`), так и через запятую (`4,5`).

Отдельное задание можно запустить и без меню:

```bash
cd LB-1/tasks
python task5_digits_sum.py
```

или из каталога работы:

```bash
python -m tasks.task5_digits_sum
```

## Устройство каталога лабораторной работы

Все работы оформлены по одной схеме, чтобы к ним было легко возвращаться:

```
LB-N/
├── main.py            # меню и запуск выбранного задания
├── README.md          # условие работы, таблица заданий, примеры
└── tasks/
    ├── __init__.py    # список заданий TASKS, который читает меню
    ├── common.py      # общие функции: ввод с проверкой, вывод результата
    └── task1_*.py … taskK_*.py   # по одному файлу на задание
```

Каждый файл задания содержит одинаковый набор элементов:

| Элемент | Назначение |
|---------|------------|
| `TITLE` | короткое название задания для меню |
| `STATEMENT` | текст условия и формулы, печатаются перед вводом |
| `solve(...)` | только расчёты, без ввода-вывода - удобно проверять и переиспользовать |
| `run()` | диалог с пользователем: запрос данных, вызов `solve()`, вывод результата |

В работах к тому же набору может добавляться `TASK` - дословная постановка
задачи из методички, если она нужна для сверки (так сделано в LB-2).

Такой разбор на файлы нужен не «для красоты»: условие требует, чтобы каждое
задание было в отдельном файле, а отделение расчётов (`solve`) от интерфейса
(`run`) позволяет проверять математику независимо от ввода с клавиатуры.

## Соглашения по коду

* интерфейс, комментарии и docstring - на русском языке;
* каждое задание - отдельный модуль `tasks/taskN_название.py`;
* общие вспомогательные функции (ввод чисел, форматирование, пауза) вынесены
  в `tasks/common.py` и не дублируются в заданиях;
* ввод всегда проверяется: границы значений берутся из условия задачи
  (например, `R1 > R2`, `A > B`, трёхзначное число от 100 до 999,
  `x < -1` в LB-2);
* числа в ответе округляются до 4 знаков, лишние нули отбрасываются;
* при запуске Python создаёт служебные каталоги `__pycache__` - их не нужно
  добавлять в коммиты (см. `.gitignore`).

## Как добавить новую лабораторную работу

1. Создать каталог `LB-N` по схеме выше; за основу удобно взять `LB-1`.
2. Положить в `tasks/` по одному файлу на задание и подключить их
   в `tasks/__init__.py` (список `TASKS`).
3. Написать `LB-N/README.md` с условием, таблицей заданий и примером работы.
4. Добавить строку в таблицу «Список работ» этого файла.
