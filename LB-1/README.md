# Лабораторная работа №1

**Тема:** знакомство с инструментарием разработки. Арифметические операции.

Программа показывает меню из семи заданий. Пользователь вводит номер задания,
затем исходные данные; после вывода результата нажатие Enter возвращает в меню.
Пункт `0` (или `выход`) завершает работу. Некорректный ввод не «роняет»
программу: запрос повторяется с пояснением, что именно введено неверно.

## Задания

| № | Файл | Что находится |
|---|------|---------------|
| 1 | `tasks/task1_triangle.py` | Гипотенуза и периметр прямоугольного треугольника по катетам |
| 2 | `tasks/task2_circles.py` | Площади двух концентрических кругов и кольца между ними |
| 3 | `tasks/task3_candies.py` | Цена 1 кг конфет и ирисок, во сколько раз одно дороже другого |
| 4 | `tasks/task4_segments.py` | Количество отрезков длины B на отрезке длины A (`A // B`) |
| 5 | `tasks/task5_digits_sum.py` | Сумма и произведение цифр трёхзначного числа |
| 6 | `tasks/task6_reverse.py` | Число, прочитанное справа налево |
| 7 | `tasks/task7_shift_first_digit.py` | Перенос первой цифры трёхзначного числа в конец |

## Структура

Каждый файл задания устроен одинаково:

* `TITLE` - короткое название для меню;
* `STATEMENT` - условие и формулы, которые печатаются перед вводом;
* `solve(...)`- только расчёты, без ввода-вывода;
* `run()`- диалог с пользователем.

## Запуск одного задания без меню

```bash
cd LB-1/tasks
python task5_digits_sum.py
```

или из каталога `LB-1`:

```bash
python -m tasks.task5_digits_sum
```
